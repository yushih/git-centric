# Node maintenance in the web interface

Implement NODE-006 with snapshot-aware library writes, explicit typed RPC methods
and a Nodes tab sharing the existing registry loading/saving workflow.
Verify protected writes, stale edits, the browser lifecycle and packaged assets.

Verified on Linux, Python 3.12 and Node 26. From pygc, Ruff lint and format
checks and mypy passed. uv run pytest -q passed 156 tests with one Starlette
deprecation warning. From pygc/frontend, npm test passed 10 tests and npm run
build completed. uv build --offline produced a wheel and sdist. Installed the
wheel into an isolated venv and exercised its gc web entry point in Chromium
at 390px width using temporary local bare peers. Setup, registration, stale
edit rejection, draft retention after reload, URL replacement, canceled and
confirmed removal, and the finalization request count passed.
