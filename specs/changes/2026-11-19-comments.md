# Pull request conversation completion

State: verified
Related spec: [PR](../features/002-pull-requests.md)

## Scope and contract

The README's add/list/reply commands already exist. Retain their signatures and
append-only behavior; no comment-edit command, RPC or UI is specified. Preserve
original comment blobs when a different author adds a reply. Fix stored-comment
validation: malformed IDs and non-UTF-8 bodies are invalid_metadata, not caller
invalid_argument or unexpected_error. CLI targets still use invalid_argument for
malformed supplied IDs and not_found for nonexistent PRs/replies.

## Plan and acceptance

1. Normalize corrupt stored-comment failures and document that contract.
2. Test exact UTF-8 text and filenames, main and multi-target replies, different
   authors, renamed PRs, CLI stdin/arity, missing targets, and concurrent appends.
3. Run locked dependency sync, Ruff lint/format, mypy, and the Python suite.
   Inspect actual blobs, trees, refs and parent lists using independent Git.

No dependencies or package layout changes. Existing untracked workflow files
remain untouched. No comment rewrite operation is introduced, so other authors
cannot overwrite comments through this API.
