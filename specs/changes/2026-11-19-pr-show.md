# Show a pull request and its conversation

State: verified

## Contract

- SHOW-001: `gc pr show PR_ID [--repo-dir PATH]` emits JSON with keys
  `pull_request` (the full existing PR record, including origin and computed
  states) and `comments` (all comment records, exact text and full replies_to).
  Additional merge-analysis fields follow [the merge analysis contract](2026-11-19-pr-merge-analysis.md).
  Public synchronous `show_pull_request(id, directory=".")` returns
  `Result[PullRequestDetails]`. Read PR and comments from one metadata snapshot.
- SHOW-002: `--text` emits plain text: PR ID/title, compare/base, author/time,
  independent draft/closed/merged flags, and each comment exactly once in an
  indented tree with ASCII connectors. First reply ID determines placement;
  multi-target comments explicitly list all reply IDs and note the first is used
  as tree parent. Comments with no reply IDs are roots under Comments (main first).
  Siblings use existing deterministic ID order. Multiline and empty bodies render
  beneath their own headers with aligned indentation, without Markdown styling.
- SHOW-003: Help/no args describes JSON, --text, --repo-dir and PR_ID (exit 0/2).
  Usual Result errors print to stderr and exit 1; extra args exit 2. Missing and
  malformed IDs fail normally. Corrupt comments and cycles in first-parent links
  return invalid_metadata in both modes, with no partial output or infinite loop.
  Iterative traversal supports deep reply chains. No ref/index/worktree changes.
- SHOW-004: Existing --repo-dir precedence/warnings apply. No RPC/frontend,
  dependency or on-disk format changes; existing commands remain compatible.

## Plan and validation

Add the snapshot API and public record/export, then a CLI-only text renderer and
show command. Update help/docs/spec. Test JSON completeness, tree topology,
multiple parents, multiline/empty text, deep chains, failures/cycles, snapshot
consistency and repo override. Inspect refs for read-only behavior. Run locked
sync, Ruff, mypy and relevant Python tests.
